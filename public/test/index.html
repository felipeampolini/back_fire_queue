Teste de notificações

Recebe notificações do Firebase neste navegador e dispara uma notificação para ele mesmo pela API (POST /notifications).

1. Permitir notificações

O navegador gera um token: o endereço deste dispositivo no Firebase.

2. Enviar uma notificação para este navegador

Fluxo: API → fila (SQS) → worker → Firebase → este navegador. Com a aba em segundo plano, a notificação aparece no sistema.

3. Recebidas com a página aberta

  • Nenhuma ainda.

No celular

Android (Chrome): abra esta página e siga os passos acima.
iPhone (iOS 16.4+): no Safari, toque em Compartilhar → "Adicionar à Tela de Início", abra pelo ícone criado e então permita as notificações.
